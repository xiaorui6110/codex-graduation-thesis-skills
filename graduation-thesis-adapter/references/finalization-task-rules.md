# Finalization Task Rules

## Scope

Use this guide when the user asks for submission-ready manuscript delivery rather than chapter-only drafting.

## Required discipline

- Confirm source draft path and destination working path explicitly.
- Keep the original draft untouched unless user explicitly asks in-place editing.
- Treat school template as format authority and project repository as fact authority.
- Never claim submission-ready before final structural and consistency checks pass.

## Planning outputs required for composer handoff

- section keep/rewrite/delete scope
- unsupported claims removal list
- figure/table retention or redraw list
- screenshot capture plan when runtime evidence is requested
- explicit chapter replacement boundaries for partial rewrite tasks
