# Terminology Normalization Rules

## Goal

Keep manuscript terminology stable across all chapters.

## Common Terms

- `系统`: preferred main term for the implemented software system
- `平台`: use only when the context is clearly about platform-level operation or positioning
- `模块`: use for functional or technical subparts
- `功能`: use for user-visible capabilities
- `用户` and `管理员`: keep role naming consistent

## Normalization Strategy

1. Define the primary project name or system name at first mention.
2. Choose one dominant noun for the main product and reuse it.
3. Avoid switching between `系统`, `平台`, `项目`, and `应用` inside the same paragraph unless the distinction is meaningful.
4. Normalize chapter titles and subsection names to the same naming style.
