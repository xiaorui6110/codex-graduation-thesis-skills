# Final Readiness Rules

## Check Before Delivery

- headings match the target template
- numbering is consistent
- no placeholder headings remain
- no template instruction text remains
- terminology is stable
- no unsupported metrics or invented facts remain
- references section is not fabricated
- missing facts are explicitly marked instead of silently guessed

## Delivery Standard

The result should be safe to paste into the user's thesis draft, but should not be described as submission-ready unless the user has also completed formatting, references, and manual review.
