# Draft Salvage Handoff Playbook

## When to use

- User has already hand-edited parts of the draft.
- User asks for partial replacement (for example, only after chapter 2.3).
- User asks to preserve original figures/tables.

## Handoff requirements

- Record two paths: `protected_original` and `working_draft`.
- Define replacement anchors by body headings, not TOC text.
- List untouched sections explicitly.
- Mark legacy assets to preserve:
  - E-R diagrams
  - database field-description tables
  - validated historical screenshots

## Prohibited behavior

- Do not plan full overwrite when user requested partial replacement.
- Do not use vague section boundaries.
