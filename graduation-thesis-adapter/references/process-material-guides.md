# Process Material Guides

## Goal

Support process-oriented thesis artifacts in addition to the final manuscript.

## Covered Materials

- task assignment
- opening report
- mid-term inspection
- progress summary

## Writing Strategy

1. Reuse the same project-fact base as the thesis body.
2. Shift tone from final-result narrative to staged progress narrative.
3. Separate:
   - completed work
   - current issues
   - next-stage plan
4. Keep commitments realistic and verifiable.

## Common Structure

- project background and objective
- key technical route
- completed milestones
- unresolved risks and causes
- next-stage plan and expected outputs

## Constraints

- Do not claim milestones not supported by repository or user records.
- Do not invent acceptance results.
- Keep dates and stage references consistent with user-supplied timeline.
