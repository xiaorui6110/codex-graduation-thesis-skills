# Figure And Screenshot Planning Rules

## Allowed visual evidence types

- system architecture diagram
- module decomposition diagram
- workflow/sequence diagram
- E-R diagram
- real runtime screenshots from the project

## Planning checklist

- chapter placement
- evidence source
- preserve existing vs redraw decision
- required caption and numbering style
- runtime preconditions for screenshot capture

## Style constraints

- engineering-paper style only
- avoid decorative infographic style
- no unsupported labels or claims
