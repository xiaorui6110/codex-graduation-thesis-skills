# Finalization Task Rules

## Scope

Apply this guide when the target is final manuscript delivery, not chapter draft only.

## Required controls

- Edit copied working draft by default.
- Keep original draft as protected source.
- Keep all visible manuscript text consistent and clean.
- Remove template prompts, process notes, and unsupported statements.

## Completion criteria

- heading structure matches target template
- unsupported claims removed or marked `[待补充]`
- figure/table numbering and captions consistent
- final readiness checks pass
