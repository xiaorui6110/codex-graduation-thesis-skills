# Terminology Normalization Rules

## Goal

Keep thesis terminology stable across chapters.

## Baseline Terms

- `系统`: default dominant noun
- `平台`: use only when platform-level context is explicit
- `模块`: functional or technical subparts
- `功能`: user-facing capability

## Normalization Actions

1. Define the project/system name once at first appearance.
2. Reduce unnecessary noun switching inside one paragraph.
3. Keep role terms stable (`用户`, `管理员`).
4. Keep chapter/subchapter naming style consistent.
