# Rewrite Style Guides

## Goal

Improve academic readability while preserving technical truth.

## Preferred Techniques

- rebuild sentence logic instead of replacing isolated words
- vary sentence length and clause structure
- keep one core claim per sentence when possible
- reduce repetitive transitions

## Avoid

- generic promotional tone
- exaggerated innovation phrasing
- unsupported certainty words (`显著`, `全面`, `彻底`) without evidence
