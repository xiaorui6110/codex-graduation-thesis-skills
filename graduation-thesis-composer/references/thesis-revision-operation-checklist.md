# Thesis Revision Operation Checklist

## Safety

- [ ] Source and working draft paths are distinct (or user explicitly chose in-place editing).
- [ ] Working draft has timestamped backup before structural edits.

## Rewrite discipline

- [ ] Replacement scope matches user-requested section boundaries.
- [ ] TOC lines are not used as replacement anchors.
- [ ] Unsupported claims are removed or downgraded.
- [ ] Missing facts are marked `[待补充]`.

## Consistency

- [ ] Core terminology is unified.
- [ ] Heading numbering depth is consistent.
- [ ] Figure/table captions are consistent.

## Delivery

- [ ] Final readiness check completed.
- [ ] Separate rework report generated when requested.
