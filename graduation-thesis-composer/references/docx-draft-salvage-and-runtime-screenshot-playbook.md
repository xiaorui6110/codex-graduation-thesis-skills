# DOCX Draft Salvage And Runtime Screenshot Playbook

## When to use

- Continue from a hand-edited working draft.
- Preserve specific old figures/tables.
- Add real runtime screenshots to support thesis chapters.

## Working sequence

1. Confirm working draft path and backup path.
2. Identify replacement boundaries by body headings.
3. Restore legacy assets before rewriting adjacent text.
4. Add screenshot placeholders and captions near target sections.
5. Insert real runtime screenshots only after capture succeeds.

## Runtime screenshot rules

- Prefer real pages over static mockups.
- Use minimal demo data and isolated runtime config when needed.
- Keep screenshot naming aligned with chapter and section IDs.
